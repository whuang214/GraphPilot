# Design Decisions

This document centralizes the active GraphPilot design decisions and unresolved questions for the active documentation set.

Use this file as the only active place for open decisions and questions. Other active docs should describe current behavior and setup without carrying their own decision lists.

Keep each entry an index, not a spec: state the **Decision** in 1–2 sentences and the **Working default** as a brief rationale/current-behavior note. Implementation detail (function names, settings, version pins, test counts, slice-by-slice history) belongs in the linked **Source** docs, not here.

**The `Source` column is provenance, not navigation.** Each row cites the document that was
canonical *when the decision was taken*, and most of those paths predate the documentation
restructure — 215 of them no longer resolve. That is correct and deliberate: repointing them
at today's owners would claim a decision was recorded against a document that did not exist
yet. To read the current statement of any of these, start from
[`docs/README.md`](../README.md); to read the original, use `git log`.

## Status legend

- `Resolved` - the active docs already establish this decision
- `Open` - still unresolved, but a working default exists so development can continue
- `Deferred` - intentionally outside current MVP work and should be revisited later
