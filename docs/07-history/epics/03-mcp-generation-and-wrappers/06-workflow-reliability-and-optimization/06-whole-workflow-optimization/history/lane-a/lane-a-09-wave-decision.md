# Lane A Slice 09: Wave Decision

## Purpose

Compare compatible Lane A baseline/candidate cells, retain or revert the host-authoring wave, update cumulative Block 6 evidence truthfully, and hand a retained candidate to Block 7 or stop.

## Design

Compare only C0/C1, W0/W1, and I0/I1 under exact compatible controls. Retain only when user-visible host wall and correction work materially improve without quality, authority, grounding, recovery, security, or browser regression. Provider-free characterization never becomes a live speed claim, and one Todo observation never becomes representative stability.

## Included Work

- Validate every baseline/candidate manifest/result/report/reference and compatibility key.
- Compare complete wall, route/lookup/search/read work, source bytes, attempts, validation failures, JSON sizes/version refs, MCP timing, and exposed host telemetry.
- Compare provider-free and separately authorized live integration readiness/generation/quality/grounding/persistence/SVG/browser/recovery results.
- Decide retain/revert against the predeclared gate and audit the causal interpretation.
- If retained, update current canonical baseline and Block 7 handoff; if reverted, restore A03–A06 candidate behavior exactly.
- Retain immutable benchmark evidence and noninfluencing A01 capability in either outcome.
- Update integration-owned group/current-state/decision/ledger/backlog/Outcome docs without mutating Lane B evidence.
- Run final provider-free guard and complete repository checks required by the retained/reverted diff.

## Not In Scope

- Another optimization wave, representative validation, generalized hosts/repos, persistent MCP, promotion, certification, deployment, push, or live calls.

## Target Areas

- New Lane A decision/report/handoff artifacts and this Outcome.
- Integration-owned Block 6 group/current-state/decision/backlog/navigation files.
- Candidate commits only when executing the predeclared rollback.

## Exit Criteria

- Only compatible pairs receive absolute/percentage savings claims.
- Retention requires materially lower host wall, validation failures, and authoring attempts; no unexplained search/read regression; warm source work/JSON 1 rebuilds at zero; complete JSON 1/JSON 2; BDD closure; and provider-free plus authorized integration guards passing.
- A failed, incomplete, incompatible, or quality-regressing candidate is reverted without weakening the gate.
- Claim states distinguish measured, host-reported, derived, provider-free characterized, pending live proof, and not measured.
- Cumulative budget, no-rerun state, rollback, remaining risks, and Block 7/deferred work are exact.
- Independent decision audit and required full checks pass before the final commit.
