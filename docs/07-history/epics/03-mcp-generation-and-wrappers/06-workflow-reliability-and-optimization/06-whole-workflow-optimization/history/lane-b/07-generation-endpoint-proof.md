# Slice 07: Generation Endpoint Proof

## Purpose

Measure one committed generation endpoint correction under a wholly new controlled anchor identity, only after a separately explicit user authorization and provider-free live-harness path proof.

## Design

Before manifest freeze, derive every package/run/observation/event/result/terminal/browser path exactly on the active platform. Reject any path beyond the active safe limit. Use short bounded identities that remain wholly new and semantically labeled through manifest metadata rather than long path components.

## Execution Contract

- **Depends on / inputs:** committed S06 correction, passing provider-free path proof, new exact user authorization, clean source/assets/budget.
- **Outputs:** one immutable terminal candidate/browser package or durable non-generated terminal evidence, S07 Outcome.
- **Exclusive write ownership:** new package/run/observation/debug/browser/synthesis identities, isolated evaluated workspace, S07 Outcome.
- **Forbidden/shared ownership:** old identities/evidence mutation, code/docs affecting bound assets after freeze, second attempt, semantic-review/host correction, group/current-state/decision/ledger/backlog reserved for S08, `.env`, S15/Stage C.
- **Parallelism/resources:** none; sequential Azure max 9, unique short identities, isolated ports/workspace/profile, mandatory cleanup.
- **Cancellation:** absent authorization, path/resource/asset/budget/security failure, uncertain state, or material audit finding stops before dispatch or terminalizes without retry.

## Included Work

- Freeze/audit new package/run/observation/debug identities, exact correction commit/assets, medium effort, roles, aggregate/controlled budget, workspaces/ports, rollback, and no-rerun.
- Require provider-free path-length tests to fail before manifest freeze for overlong identities and pass for the selected short identities.
- Execute exactly one real stdio anchor with at most nine naturally reached sequential calls after new explicit user authorization.
- Require generation first-response validity and zero `generation_repair` calls for retention.
- Keep semantic-review first-response/repair behavior unchanged as a control.
- Run exact readiness/meaning/provenance/review/persistence/SVG/browser/compatibility/recovery proof and current provider-free guard.
- Terminalize every state and independently audit evidence/resource cleanup.

## Not In Scope

Using the completed semantic-review wave authorization; second attempt; semantic-review or host correction; unrelated optimization; representative claims; promotion/certification/deployment; S15/Stage C.

## Target Areas

New generation-wave authorization/package/run/browser/synthesis identities and this group's `evidence/generation-endpoint-wave/`.

## Exit Criteria

- New explicit user authorization exists for one exact candidate and maximum call budget.
- Every derived artifact path passes the pre-freeze platform limit.
- Exactly one new candidate becomes immutable terminal; no retry occurs.
- Generation is first-response valid with no generation-repair role, or retention fails.
- Semantic-review behavior remains unchanged; all quality/provenance/browser/compatibility gates pass.
- Independent audit has no critical/high/medium finding.
