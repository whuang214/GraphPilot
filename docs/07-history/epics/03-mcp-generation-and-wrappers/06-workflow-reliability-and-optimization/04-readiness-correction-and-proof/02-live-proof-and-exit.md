- **Depends on / inputs:** committed S01 correction, clean exact HEAD, all offline gates/audit passed, 996-call remaining budget before proof, absent new identities.
- **Outputs:** audited manifest, immutable observation/terminal/event ledger, before/after result JSON/Markdown, this Outcome/group/current-state, Captain report, and Block 5 decision.
- **Exclusive write ownership:** new Block 4 diagnosis identities, Block 4 evidence/Outcome/status, ignored supervisor state/report.
