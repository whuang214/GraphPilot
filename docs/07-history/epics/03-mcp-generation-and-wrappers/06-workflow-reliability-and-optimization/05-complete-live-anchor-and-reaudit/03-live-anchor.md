# Slice 03: Live Anchor

## Purpose

Execute the committed human-approved anchor once through host preparation, real stdio MCP, production readiness/generation/review, persistence/rendering, API load, and visible editor completion with complete safe critical-path evidence.

## Design

Freeze one new manifest against the clean S01+S02 integration commit. Materialize the exact anchor source into a unique evaluated workspace; keep control artifacts separate. Start unique backend/frontend/browser resources only after pre-dispatch audit. Execute one stdio MCP workflow and let natural role transitions consume up to the nine-call schedule.

## Execution Contract

- **Depends on / inputs:** committed S01 approval and S02 harness, clean exact HEAD, approved anchor/approval digest, configured provider, 995 calls remaining, absent identities, clean unique resources.
- **Outputs:** one immutable live-anchor run/result, generated diagram/SVG/editor proof or durable blocked/failure/uncertain evidence, S03 Outcome/status/Captain update.
- **Exclusive write ownership:** new Block 5 package/run/observation/call/browser identities and generated evaluated workspace; S03 evidence/Outcome; ignored supervisor state.
- **Forbidden/shared ownership:** code/docs affecting bound assets after freeze, another live package, E1/E2/Block4 identities, user canonical workspace, accepted baselines, optimization, `.env`, S15/Stage C.
- **Resources:** sequential provider schedule; ports 15174 frontend and 18081 backend; browser profile `block5-live-anchor`; unique evaluated/control roots; mandatory cleanup.
- **Cancellation:** approval missing/mismatch, dirty/stale asset, role/budget/identity audit failure, resource conflict, credentials/permissions issue, uncertain unterminalizable state, security conflict, or destructive/dependency need.

## Included Work

- Freeze and independently audit manifest/case/approval/source/assets/workspaces/roles/order/budget/scope/rollback/resources.
- Capture host start, source reads/bytes, JSON authoring/reconciliation, and unavailable host token/credit fields truthfully.
- Execute exactly one `diagram_generate_from_context` through real stdio MCP with `require_ready` and new debug/run identities.
- Persist all safe provider/local/MCP evidence and stop downstream roles naturally on block/failure.
- On generated outcome, verify canonical JSON/schema/provenance/context stability, reviewed quality/final review, ownership, SVG, and exact editor link.
- Start isolated backend/built frontend; use real browser to verify API load, visible exact identity/counts, console/page/network cleanliness, and completion timing; clean resources.
- Compare required/forbidden checklist without sending it to provider.
- Independently audit terminal evidence, accounting, quality, leakage, and no-rerun.
- Immediately after MCP terminal result, classify `blocked`, `error`, or `interrupted` as non-generated; stop S03 after durable terminal/result audit, keep S04 blocked, record the exact known owner, and make no favorable rerun. A generated result that fails quality/provenance/render/API/browser visibility also stops S03 after its evidence audit and does not authorize S04.
