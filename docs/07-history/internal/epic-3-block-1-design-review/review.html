Section decision

Contracts and Evidence Model

Versioned inputs and outputs make the audit rerunnable and comparisons truthful.

2
  • Retain W01–W22 as stable detailed IDs mapped to Block 1's ten broad areas.
  • Use non-overlapping host, azure, mcp, local, browser, and residual accounting.
  • Every value has status, source, reason, and confidence. Unavailable is null; zero requires observed zero or explicit provider-free not_called.
  • Add bounded namespace-first scenario-set, external-evidence, run-manifest, observation, report, and baseline-ledger contracts.
  • Default scenarios use new identities with no S15/H/M/full-effort runtime dependency: six basic/complex type anchors plus the smallest blocked, repair, failure/interruption, recovery, and no-rerun guards.
  • Fake-provider time remains local harness time; host credits remain separate; no provider or host value is estimated.

The first implementation slice defines storage, ledger, compatibility, and security contracts before runner code, preventing the artifact model from being backfilled around implementation.

Section decision

Capture, Recovery, and Browser Proof

Evaluation-only adapters cover external boundaries without changing production acceptance.

3
  • A provider-free fixture-host adapter and optional validated external-host importer represent W01–W05.
  • An evaluation-only capturing client wraps the existing LLM seam and records role/state, bytes, duration, tokens, cache, provider identity/tier, and requested/effective controls. The production observer event contract is unchanged.
  • The existing generation observer retains stage/candidate/repair/quality/result evidence; real stdio measures startup, discovery, transport, serialization, response bytes, and recovery.
  • Immutable observations and terminal identities prove blocked, failure/interruption, finalized recovery, and no unchanged rerun.
  • Playwright uses built Vite preview and existing dedicated ports 15173/18080. One exact generated representative loads cold and warm with API timing, visible diagram identity, and console/page/network checks.
  • W22 may be omitted only for a diagnostic report. Any recorded baseline fails closed without browser proof.

Instrumentation equivalence must prove identical provider-call order, result, canonical JSON, SVG, and writes. Capture callback failures remain isolated from production behavior.

Section decision

Reports, Ranking, and Baselines

Immutable run evidence becomes a bounded, comparable Block 2 input.

4

Store non-canonical packages below .graphpilot/evaluation/workflow-audit/: immutable run manifest/observations, browser evidence, machine-authoritative JSON, human Markdown, and one logical append-only baseline ledger.

  • Artifacts contain safe metrics, identities, versions, output digests, and byte counts, never raw source, prompts, provider responses, hidden reasoning, secrets, or hidden gold.
  • Ledger updates are bounded and atomic with expected-digest checks. Duplicate IDs and stale/concurrent writers fail.
  • Comparison requires an exact compatibility key over audit/report/scenario/schedule/assets/dependencies/platform/browser mode; otherwise results are explicitly incomparable.
  • S13–S15 remain prior evidence only, never ledger baselines.
  • Deterministic ranking prioritizes reliability/quality failure, then valid complete-wall contribution, then attribution-blocking unknowns.
  • Every finding contains evidence refs, owner confidence, proven fix or smallest diagnostic proof, alternative, trade-off, benefit ceiling, offline/live proof, and disposition. No model output changes behavior.
